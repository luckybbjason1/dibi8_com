简介#

mattpocock/skills 达到 267,501 stars——2026年9月最高分的agent skills。由 Matt Pocock 创建，他是世界顶级TypeScript专家，拥有TypeScript Mastery课程和大量高质量学习资料。

核心理念： “Straight from my .agents directory”——实战技能，非空谈。

TypeScript & JavaScript#

  • type-safety-first — everywhere enforce type checking
  • react-patterns — 现代React模式（hooks、context、状态管理）
  • testing-library-best-practices — 有效测试
  • typescript-advanced-types — 条件类型、映射类型、推断

API & Backend#

  • rest-api-design — RESTful API设计原则
  • graphql-schema-design — GraphQL schema最佳实践
  • database-orm-patterns — Prisma、Drizzle、TypeORM模式
  • api-security-checklist — 认证、授权、验证

DevOps & 基础设施#

  • docker-optimization — 多阶段构建、镜像大小优化
  • ci-cd-pipeline-design — GitHub Actions、GitLab CI模式
  • kubernetes-basics — pods、services、deployments
  • infrastructure-as-code — Terraform、Pulumi模式

性能与优化#

  • react-performance — memoization、代码分割、bundle分析
