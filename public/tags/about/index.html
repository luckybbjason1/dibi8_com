About dibi8

About dibi8 我是Jason，一个关注AI Agent生态的开发者。 这个网站是我实测AI Coding工具的个人项目，目的是帮助开发者找到真正好用的开源AI工具。 为什么做这个 我在Android Termux上使用Hermes Agent开发自动化脚本时，发现AI Coding Agent生态发展太快——每周都有新工具出现。但我找不到一个靠谱的筛选平台，大部分内容要么是AI生成的模板文，要么是硬广软文。 所以我决定自己做一个：只放我真实测试过的工具，如实写出优缺点，不写广告。 技术栈 开发: Python, Termux (Android ARM64), Hermes Agent 站点: Hugo静态站点，PaperMod主题 部署: Cloudflare Pages（自动构建推送） 数据源: GitHub API, PyPI, npm 内容原则 真实测试 - 每篇评测文章都经过我实际使用 透明标注 - 标注测试日期、环境、失败案例 无硬广 - 不接赞助，不写软文，affiliate链接会明确标注 多语言 - 支持中文、英文、韩语、越南语（人工审核翻译） 联系 GitHub: luckybbjason1 Telegram: DIBI8群组 邮件: contact@dibi8.com 最后更新：2026-09-22
