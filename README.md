# dibi8_com — dibi8.com 内容备份仓库

dibi8.com 上线文章的镜像备份。每次 dibi8 上线新文章必须同步备案到这里。

## 目录映射

| 目录 | 说明 |
|---|---|
| `CN/` | 中文内容（主要语言） |

## 翻译工具

网站使用 Google Translate 提供在线翻译，支持 14+ 种语言：
- 中文、英语、韩语、越南语
- 日语、法语、德语、西班牙语
- 阿拉伯语、葡萄牙语、俄语、印地语
- 泰语、印尼语

## 用途

- 灾难恢复：dibi8 站点内容丢失时从此仓库重建
- 版本控制：所有文章内容通过 Git 管理
- AI 友好：支持 llms.txt 供 AI 爬虫索引
