# DIBI8 Coin 页面设计方案 v2.0

**重要声明**: 本页面为品牌叙事设计，非真实代币发行。DIBI8 Coin 是 dibi8.com 平台价值的象征性表达。

---

## 项目概述
为 dibi8.com 创建 DIBI8 Coin 品牌叙事页面，采用 Bento Grid 布局和 Web3 美学风格。

## 设计目标
1. **品牌强化** - 建立 DIBI8 的社区价值和品牌识别
2. **社区激励** - 传达社区贡献的价值认可
3. **视觉冲击** - 使用现代化的 Bento Grid + Web3 美学
4. **六维对称** - 六个核心维度的平衡布局
5. **用户易用** - 清晰的导航和直观的信息层级

## 六维对称题材定义（基于真实内容）

### 维度 1: 社区 (Community)
- **核心**: 真实的Telegram社区 (https://t.me/DIBI8_Group)
- **数据**: 493+工具收录，每日更新
- **叙事**: 开发者共同构建的AI工具发现平台

### 维度 2: 激励 (Incentives)
- **核心**: 社区贡献认可机制
- **形式**: 积分系统、贡献排行榜（概念设计，非区块链代币）
- **叙事**: 每一次推荐、评论、贡献都被看见

### 维度 3: 治理 (Governance)
- **核心**: 社区民主决策愿景
- **形式**: 提案投票透明机制（未来规划）
- **叙事**: 每个成员都有平等的发言权

### 维度 4: 技术 (Technology)
- **核心**: 平台技术架构
- **事实**: Hugo静态站、Tailwind CSS、Web3美学设计
- **叙事**: 安全可靠的技术底座

### 维度 5: 生态 (Ecosystem)
- **核心**: 现有工具收录网络
- **事实**: 493个工具，5大分类（AI编程助手401、LLM框架53等）
- **叙事**: 连接工具、用户和价值的网络

### 维度 6: 愿景 (Vision)
- **核心**: AI民主化使命
- **事实**: "让AI工具触手可及"
- **叙事**: 从中心到去中心化的价值回归

## 设计风格规范

### 色彩系统
| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 背景主色 | #0a0a0f | 深空黑 |
| 背景次色 | #12121a | 深色区域 |
| 主要文字 | #f1f5f9 | 高对比度 |
| 次要文字 | #cbd5e1 | 中层对比度 |
| 霓虹紫 | #8b5cf6 | 主品牌色 |
| 霓虹青 | #22d3ee | 辅助品牌色 |
| 霓虹粉 | #f472b6 | 强调色 |
| 霓虹绿 | #34d399 | 成功/正向 |

### 组件系统
- `.coin-card` - 玻璃态卡片组件
- `.gradient-text` - 渐变文字效果
- `.glow` - 霓虹发光效果
- `.bento-grid` - 响应式网格布局

### 响应式断点
- 桌面 (lg): 4列网格
- 平板 (md): 2列网格
- 手机 (sm): 1列堆叠
