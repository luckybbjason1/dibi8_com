## 二、Bento Grid 系统规范

### 2.1 网格基础

```css
.bento-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 1.5rem;
}

@media (max-width: 1024px) {
  .bento-grid { grid-template-columns: repeat(2, 1fr); }
}

@media (max-width: 640px) {
  .bento-grid { grid-template-columns: 1fr; }
}
```

### 2.2 卡片跨度系统

| 类名 | 网格跨度 | 用途 |
|------|---------|------|
| `.span-4` | 4列 (全宽) | Hero, 大型CTA |
| `.span-3` | 3列 | 大信息卡片 |
| `.span-2` | 2列 | 中等信息卡片 |
| `.span-1` | 1列 | 标准信息卡片 |
| `.span-row-2` | 2行高 | 强调卡片 |

### 2.3 对称布局规则

**六维对称原则**:
1. **视觉平衡**: 六个维度在网格中均匀分布
2. **信息层级**: Hero > 维度卡片 > CTA
3. **色彩呼应**: 霓虹紫→青→粉渐变贯穿全站
4. **间距一致**: 统一的 `gap: 1.5rem` 和 `padding: 1.5rem`

## 四、对称题材视觉规范

### 4.1 色彩对称

```
主色调分布:
┌─────────────────────────────────────────────────────┐
│  Hero    → 紫色→青色渐变光晕                       │
│  Community → 绿色强调                              │
│  Incentives → 粉色强调                              │
│  Governance → 紫色强调                              │
│  Vision   → 青色强调                                │
│  Technology → 青紫渐变                              │
│  Ecosystem → 粉色强调                               │
│  CTA      → 紫色主按钮 + 青色次要按钮              │
└─────────────────────────────────────────────────────┘
```

### 4.2 圆角对称

```css
/* 所有卡片统一圆角 */
.coin-card {
  border-radius: 1.5rem; /* 24px */
}

/* 小卡片微调 */
.coin-card--small {
  border-radius: 1rem; /* 16px */
}
```

### 4.3 间距对称

```css
/* 全局间距系统 */
--space-grid: 1.5rem;     /* 网格间距 */
--space-card: 1.5rem;     /* 卡片内边距 */
--space-section: 4rem;    /* 区块间距 */

/* 内容区块上下对称 */
section {
  padding-top: var(--space-section);
  padding-bottom: var(--space-section);
}
```

## 五、响应式断点设计

| 断点 | 设备类型 | 网格配置 | 特殊处理 |
|------|---------|---------|---------|
| `≥1024px` | 桌面 | 4列网格 | 完整Bento布局 |
| `768px-1023px` | 平板 | 2列网格 | Hero变为2×2，CTA堆叠 |
| `≤767px` | 手机 | 1列堆叠 | 所有卡片垂直排列 |

### 5.1 移动端优化

```css
@media (max-width: 767px) {
  .bento-grid {
    grid-template-columns: 1fr;
    gap: 1rem;
  }
  
  .coin-card {
    min-height: auto;
  }
  
  .hero-section {
    min-height: 50vh;
  }
  
  /* 隐藏装饰性动画 */
  .particle {
    display: none;
  }
}
```
